# 🤖 Настройка Telegram бота

## Как работает бот

1. **Пользователь открывает бота** и нажимает `/start`
2. **Бот отправляет последний отчет** и добавляет пользователя в список подписчиков
3. **При создании нового отчета** бот автоматически отправляет его всем подписчикам

## Два режима работы

### Режим 1: Интерактивный бот (для обработки /start)

Бот должен работать постоянно, чтобы обрабатывать команды пользователей.

**Запуск:**
```bash
python run_bot.py
```

**Где запускать:**
- На вашем компьютере (для тестирования)
- На облачном сервисе (Railway, Render, Heroku) - для постоянной работы

### Режим 2: Отправка отчетов (автоматически)

При создании нового отчета (через GitHub Actions или вручную), отчет автоматически отправляется всем подписанным пользователям.

**Работает автоматически** при запуске `main.py`

## Настройка

### Шаг 1: Создайте бота

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте `/newbot`
3. Получите токен бота

### Шаг 2: Настройте переменные окружения

В `.env` файл (для локального запуска):
```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

В GitHub Secrets (для автоматической отправки):
- `TELEGRAM_BOT_TOKEN` = ваш токен бота

### Шаг 3: Запустите бота

**Для тестирования локально:**
```bash
python run_bot.py
```

**Для постоянной работы:**
- Используйте Railway, Render или другой облачный сервис
- Запустите `python run_bot.py` как отдельный процесс

## Команды бота

- `/start` - подписаться на отчеты и получить последний отчет
- `/help` - показать справку

## Как это работает вместе

1. **Бот работает постоянно** (`run_bot.py`) - обрабатывает команды `/start`
2. **GitHub Actions запускается по расписанию** - создает отчеты и отправляет подписчикам
3. **Пользователи получают отчеты автоматически** при каждом новом анализе

## Деплой бота на облачный сервис

### Railway (рекомендуется - бесплатный tier)

1. Создайте аккаунт на [railway.app](https://railway.app)
2. Создайте новый проект
3. Подключите GitHub репозиторий
4. Настройте переменные окружения:
   - `TELEGRAM_BOT_TOKEN`
5. Установите команду запуска: `python run_bot.py`
6. Railway автоматически запустит бота

### Render

1. Создайте аккаунт на [render.com](https://render.com)
2. Создайте новый Background Worker
3. Подключите GitHub репозиторий
4. Настройте:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python run_bot.py`
   - Environment Variables: `TELEGRAM_BOT_TOKEN`

### Heroku

1. Создайте `Procfile`:
   ```
   worker: python run_bot.py
   ```
2. Задеплойте:
   ```bash
   heroku create your-bot-name
   heroku config:set TELEGRAM_BOT_TOKEN=your_token
   git push heroku main
   ```

## Важно

- Бот должен работать **постоянно** для обработки команд `/start`
- GitHub Actions **не нужен** для работы бота - он только отправляет отчеты
- Можно запустить бота на одном сервисе, а GitHub Actions использовать отдельно
