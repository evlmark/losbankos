# 🔄 Как это работает

## Архитектура системы

### 1. Telegram бот (интерактивный)

**Файл:** `run_bot.py`

**Что делает:**
- Обрабатывает команды `/start` и `/help`
- При `/start` отправляет последний отчет и добавляет пользователя в подписчики
- Должен работать **постоянно** для обработки команд

**Где запускать:**
- Локально (для тестирования): `python run_bot.py`
- На облачном сервисе (Railway, Render) - для постоянной работы

### 2. Анализ и отправка отчетов

**Файл:** `main.py`

**Что делает:**
- Собирает отзывы из сторов
- Анализирует их
- Создает отчеты
- **Автоматически отправляет отчеты всем подписчикам**

**Где запускать:**
- Вручную: `python main.py`
- GitHub Actions (автоматически по расписанию)
- Cron job на сервере

## Поток работы

```
1. Пользователь → /start → Бот отправляет последний отчет
                                    ↓
2. Пользователь добавлен в список подписчиков
                                    ↓
3. GitHub Actions запускается (каждый понедельник)
                                    ↓
4. main.py собирает отзывы и создает отчет
                                    ↓
5. main.py отправляет отчет всем подписчикам автоматически
```

## Настройка для полной автоматизации

### Вариант 1: GitHub Actions + Облачный сервис для бота

1. **GitHub Actions** - запускает анализ по расписанию
   - Настройте `.github/workflows/weekly_reviews.yml`
   - Добавьте `TELEGRAM_BOT_TOKEN` в Secrets
   - Отчеты будут отправляться автоматически

2. **Облачный сервис (Railway/Render)** - запускает бота для `/start`
   - Задеплойте `run_bot.py`
   - Бот будет обрабатывать команды пользователей

### Вариант 2: Все на одном сервере

1. Запустите бота: `python run_bot.py &` (в фоне)
2. Настройте cron для запуска `main.py` по расписанию

## Файлы подписчиков

Список подписчиков сохраняется в:
```
data/telegram_subscribers.json
```

Этот файл должен быть доступен и для бота, и для main.py (если они на разных серверах, нужно синхронизировать).

## Важно

- Бот (`run_bot.py`) должен работать **постоянно** для обработки `/start`
- `main.py` запускается **периодически** (по расписанию) и отправляет отчеты
- Подписчики хранятся в `data/telegram_subscribers.json`
